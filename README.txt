ITAS RCA Analyzer – portable

1. Datei ITAS_RCA_Analyzer_Portable.html doppelt anklicken (oeffnet im Browser).
2. Jira-CSV laden ODER Incidents manuell anlegen (Karte 1b). Die Analyse startet automatisch und erzeugt fuer jedes Ticket einen Feedback-Datensatz.
3. Tickets werden automatisch in Gruppen konsolidiert; per Umschalter "Nach Gruppe konsolidieren" gruppiert anzeigen.
4. Sortieren nach Impact, Ressourcenverbrauch oder Komplexitaet ueber das Auswahlfeld "Sortieren nach".
5. Ansicht "Karten" waehlen: Titelleiste je Karte farblich einstellbar; Klick auf eine Karte oeffnet die Detailansicht.
6. Optional eine eigene Feedback-Datei (CSV oder JSON) laden. Es wird kein vorgefuelltes Beispiel-Feedback geladen.

WICHTIG - Daten bei neuer Version behalten:
Manuell angelegte Tickets und Feedback werden lokal im Browser gespeichert und bleiben
bei gleicher Datei automatisch erhalten, auch wenn die HTML durch eine neue Version ersetzt wird.
Fuer Umzug auf neue Version / anderen Rechner: unter "5. Backup & Migration" ein vollstaendiges
Backup exportieren und dort wieder importieren.

Keine Installation, kein Terminal, keine Adminrechte, keine Netzwerkverbindung erforderlich.
