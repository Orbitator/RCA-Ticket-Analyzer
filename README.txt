ITAS RCA Analyzer – portable

1. Datei ITAS_RCA_Analyzer_Portable.html doppelt anklicken (oeffnet im Browser).
2. Jira-CSV laden ODER Incidents manuell anlegen (Karte 1b). Die Analyse startet automatisch und erzeugt fuer jedes Ticket einen Feedback-Datensatz.
3. Tickets werden automatisch in Gruppen konsolidiert; per Umschalter "Nach Gruppe konsolidieren" gruppiert anzeigen.
4. Sortieren nach Impact, Ressourcenverbrauch oder Komplexitaet ueber das Auswahlfeld "Sortieren nach".
5. Optional eine eigene Feedback-Datei (CSV oder JSON) laden. Es wird kein vorgefuelltes Beispiel-Feedback geladen.

Keine Installation, kein Terminal, keine Adminrechte, keine Netzwerkverbindung erforderlich.
